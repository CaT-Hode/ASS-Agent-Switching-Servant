# v0.3.41

- 官方订阅模型的注入目录逐字段保留 Codex 原生元数据；不再应用 ASS 的旧上下文、推理强度、名称或隐藏覆盖。原生缓存更新后，只更新已应用目录中的官方模型，不应用待保存的第三方路由。
- Codex 接入记录保留加密的已应用副本；记录文件缺失时通过归属校验恢复，损坏记录和外部配置修改仍拒绝覆盖。
- DSH、Pi 的运行时目录过滤仍由 ASS 完整持有的注入项，避免显示额外原生供应商；原生新增模型和外部修改的配置保留可见。
- 原生客户端状态暂不可读时，保留上次账户快照并独立刷新已保存供应商，避免 WOYAO 等供应商随扫描失败而从画面消失。
- 后台供应商发现和 OAuth 定时扫描增加错误边界；配置写入在重命名前同步到磁盘，供应商及客户端配置各保留一份前代备份。旧客户端配置快照不能覆盖外部新修改。
- 新增小型加密运行诊断记录，用于区分启动、退出、后台错误和 renderer 退出；不记录错误正文、请求或凭据。
- 增加 Codex「提示词预测兼容（实验）」开关，通过原生 OpenAI 通道使用 ASS 模型路由，并转换 Chat/Anthropic 所需的结构化输出格式。默认关闭，无账号模式不启用；不绕过官方登录、功能开放或内容检查，已有 ASS 对话的供应商绑定不改写。

验证与边界见 [本轮说明](QA-v0.3.41.md)。本轮不自动提交或推送。
