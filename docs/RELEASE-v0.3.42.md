# v0.3.42

- Codex 接入记录新增独立加密检查点及前代检查点，补齐旧版已应用记录缺少恢复副本的情况。记录丢失或 JSON 半写时自动恢复；没有检查点时，可从可验证且无歧义的原始 TOML 备份重建。
- 原生配置写入器移除或破坏 ASS 注释标记时，验证完整连接字段后自动重建标记，保留模型选择、原生偏好、账户和历史。
- 自动恢复使用事务、加密故障备份和路由并发检查，写盘失败可以重试，旧进程不会覆盖新的路由记录。备份扫描及检查点保留大小上限。
- 「启动 Codex」会尝试唤起已有窗口；可选官方服务中转准备失败时，按当前本机配置打开，并明确显示通道未就绪。实际启动失败仍报错，不会通过另一入口重复启动。

本轮共 161 项针对性回归有通过记录（155 项核心与集成回归、6 项真实 React renderer 测试），未重复运行整个测试集。复现使用 v0.3.41 安装包代码、虚拟凭据和隔离目录；网络仅使用本地模拟服务。详情见 [验证记录](QA-v0.3.42.md)。
