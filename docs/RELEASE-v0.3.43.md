# v0.3.43

- 一键修复与普通切换的预检查独立执行；普通检查卡住、修复预检查失败、执行失败均不再让修复按钮永久禁用。失败后可直接在原弹窗重试，重新获取修复确认。
- 已开启接入的客户端保留手动修复入口；安装位置不明确、进程检查失败时仍可只修复配置。关闭和重启仍需另行明确选择有效目标。
- 可校验的未完成路由写入事务支持通过一键修复回滚，再恢复上次已应用的接入。磁盘写入失败保留事务，恢复空间后可以重试；不扩大到其他客户端。
- 内容不完整但仍能解析的接入记录可从独立可信副本恢复，完整记录中的外部归属冲突仍保持不覆盖。旧版接入记录在修复时补齐加密恢复副本。
- 迟到的检查或修复结果不会关闭、改写后来打开的其他客户端弹窗；默认不关闭客户端，不应用未同步模型编辑。

已完成 141 项核心与集成回归及 6 项真实 React renderer 回归。测试使用隔离假数据，不执行真实 OAuth 登录或关闭用户客户端。
