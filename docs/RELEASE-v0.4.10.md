# v0.4.10

修复普通官方账号登录时，ASS 注入后 Codex 原生归档大量消失的问题。Codex 归档页的 `thread/list` 请求使用 `modelProviders: null`，只显示当前默认供应商；旧版普通注入将默认供应商从 `openai` 改为 `ASS`，原生归档因而被筛掉。

普通 OAuth 接入现在默认保留 `openai` 身份，通过原有本地入口分流官方和第三方模型，不再需要手动开启“提示词预测兼容”。已有接入显示待同步，只有明确更新接入才更改配置；重新加载 Codex 后生效。无账号模式保持独立供应商。官方原生功能仍受账号与模型的支持范围约束。

此修复不改写归档正文、压缩文件、模型绑定、归档状态和时间，也不迁移其他旧供应商的记录。旧 ASS 对话的预测绑定仍可通过原有按钮在 Codex 正常退出后修复。

使用当前安装的 Codex 原生后端、隔离目录和本地模拟服务验证：普通接入前后以及断开后，两条原生归档均可通过归档页相同的默认筛选列出，其中一条为 `.jsonl.zst`；第三方注入模型请求仍进入本地服务；所有归档字节不变，旧 `aimai1` 记录归属保留。没有发送实网模型请求，也没有关闭正在运行的 ASS 或 Codex。
