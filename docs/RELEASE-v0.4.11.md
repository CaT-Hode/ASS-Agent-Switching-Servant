# v0.4.11

修复 Codex 长回复在约 300 秒被 ASS 主动断开，随后报 `stream closed before response.completed` 的问题。

Codex 模型请求现在采用连续 5 分钟无上游数据才超时的规则。收到响应头、正文数据或 SSE 心跳会重新计时；持续输出的请求没有固定 5 分钟总上限。计时在协议解析前观察原始字节，覆盖官方 Responses、第三方 Responses、协议转换及压缩请求，不改写流内容或伪造完成事件。

空闲超时记录为 `upstream_idle_timeout`；尚未向客户端发送响应头时返回 HTTP 504，已经开始流式输出时发送明确的错误事件。客户端取消单独记录为“请求已取消”。连通性测试仍有独立的 30 秒总时限，账户、图片和其他客户端的时限保持原有规则。

本机更新使用保留运行实例的方式，在下次启动 ASS 时加载；不会关闭 ASS 或 Codex，也不更改账户与接入配置。

94 项相关回归通过；虚拟时钟验证持续活动的流可跨过原 5 分钟上限。打包代码还通过真实 Electron `net.fetch` 和本地模拟上游检查，使用缩短的测试时限验证续时、停滞中止和原始字节保留；打包窗口检查通过。没有发送实网模型请求。
