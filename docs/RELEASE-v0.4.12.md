# v0.4.12

修复 MIFYTEAM `vertex_ai/gemini-4-argon` 在基础文本检测通过后，实际 Codex 工具请求仍失败的问题。

- MIFYTEAM Gemini 不再转发其网关明确拒绝的可选原生 `web_search` 声明，同时给模型加入搜索能力提示并记录省略项；强制搜索仍明确报错。
- 该网关转换到 Vertex 时会丢失数组参数的 `items`。仅对含数组参数的函数，将完整 JSON 参数编码为字符串，并保留原参数 schema 说明；返回 Codex 时还原函数名称、命名空间及 JSON 参数，历史调用同步转换。其他函数保留原 schema，不执行或删除客户端工具。
- 兼容范围按 MIFYTEAM 的准确端点及 Gemini 模型匹配，支持显式原生工具模式覆盖。其他供应商沿用原规则，WOYAO 的混合搜索处理保持不变。
- 上游以 SSE 返回 HTTP 错误时，ASS 保留错误信息及参数说明，敏感凭据继续脱敏，避免只显示“上游返回 HTTP 400”。

Anthropic Messages 当前仍未通过实测，不将它改判为可用。基础文本检测通过也不代表所有原生工具都已验证。本次不重试用户任务、不更改既有对话；本机更新在下次正常启动 ASS 时生效。

实网验证使用当前 Codex 生成的完整 16 项工具声明，原始请求含搜索及数组 schema 时失败，修复后完整结束；另一次强制数组工具调用正确还原函数名、命名空间和数组参数，没有执行该工具。回归覆盖历史调用、分段参数、其他供应商隔离及 SSE 错误脱敏。
