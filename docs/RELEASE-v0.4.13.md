# v0.4.13

客户端注入页展开供应商后，可在每个模型行选择接口协议：自动、Responses、Anthropic Messages、Chat Completions。

- 选择按客户端和模型独立保存，不修改共享供应商配置。自动模式沿用已有检测规则；固定协议在同步接入后优先于检测结果。
- 保存选择后显示待同步，当前路由继续使用已同步设置。同步后，Codex / Claude 路由及原生配置注入均采用所选协议；重启后保留，切回自动后同步即可恢复自动选择。
- 模型改名时保留选择，删除模型时移除对应设置。Codex 的工具兼容菜单按最终协议显示，Responses 保留原有自动 / 兼容 / 原生选项。

验证覆盖客户端隔离、持久保存、模型改名与删除、同步前后的实际路由、自动检测不覆盖手动选择、原生配置及界面交互。桌面浅色与深色布局检查无裁切。本机更新保留当前运行的 ASS，在下次正常启动时生效。
