# v0.4.15

请求监控现在同时展示进行中与已完成请求，模型名称继续复用 ASS 的最后一级归并。

- 进行中请求置顶，区分等待上游、等待首输出与生成中，每秒更新耗时、输出量及 TPS。详情也随请求更新；结束后同一请求 ID 转为完成记录，不重复计数。暂停刷新冻结当前显示，恢复后立即追上实时状态。
- 尚未收到增量用量时，输出量与 TPS 标记“≈”估算：ASCII 约 4 字符/token，其他字符约 1 字符/token。优先使用上游已报告的用量，结束后用实际数字结算；估算不进入历史用量、成功率与缓存统计。并发时顶部实时 TPS 为当前请求吞吐合计。
- 活跃记录只保存在当前路由内存中，不保存正文。每秒查询使用历史版本号，仅在历史改变时传回历史列表。离开页面、隐藏窗口或暂停时停止轮询；中断及取消移除活跃行并保留正常失败记录。

全局沿用 `cubic-bezier(0.23,1,0.32,1)`：

| 界面 | 动效及用途 |
| --- | --- |
| 主页面、供应商详情、客户端与项目切换 | 入场 180ms、退场 110ms，透明度和轻微纵向移动，衔接内容替换 |
| Token 柱图、监控柱图与用量条 | 首次载入 260ms 从零展开，说明数量方向；实时刷新不重新播放 |
| 请求详情、通知与菜单 | 入场 180ms、退场 120ms，保持相同方向，退出完成后移除 |
| 减少动态效果 | 80ms 轻微淡入，不位移、缩放；键盘导航立即提交 |

沿用现有弹窗进出动画；不动画化每秒数值、搜索输入、焦点移动或对话正文。页面动画可打断，连续导航以最后一次选择为准，并与既有主题圆形切换互不抢占。

验证覆盖进行中请求的完整生命周期、实时估算与最终计量、模型归并、刷新暂停、页面快速切换、图表起始状态、减弱动态效果及打包程序的全部主导航。本机更新使用保留运行进程的安装方式，在下次正常启动时生效。
