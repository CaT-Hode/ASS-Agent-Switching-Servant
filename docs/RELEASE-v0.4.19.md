# v0.4.19

页面切换现在表达导航的空间关系：

| 操作 | 过渡效果 |
| --- | --- |
| 选择左侧更靠下的主页面 | 新内容从下方 22px 进入，旧内容向上 14px 淡出；入场 200ms、退场 130ms |
| 选择左侧更靠上的主页面 | 反向纵向过渡，时长相同 |
| 进入供应商详情 / 返回列表 | 左右推进 / 返回，带轻微缩放；入场 180ms、退场 110ms |
| 同层标签、筛选及内容切换 | 纯淡入淡出，入场 160ms、退场 100ms |

主导航位置、名称及标题共用一份定义。方向以实际已显示页面为起点，连续点击仍取最后一次选择；同一主页面重复点击不重新播放。沿用已有原生快照和退出处理，仅复用现有过渡标记传递方向，不增加动画库或保留旧 React 页面。键盘操作即时提交；减少动态效果时使用 80ms 淡入，主题圆形切换保持独立。

验证读取实际动画关键帧，检查上下反向、详情层级、同层淡入、连续导航与减少动态效果；同时检查打包程序的真实左侧导航顺序。本机安装保留运行中的 ASS 与 Codex，新效果在下次正常启动 ASS 时生效。
