# v0.4.2

供应商网络出口新增“直接连接 · HTTPS DNS（仅此供应商）”。

- 仅显式启用的供应商使用独立会话；普通直连和系统代理不变。
- HTTPS DNS 查询不携带供应商密钥、请求头或对话，只查询目标域名。
- 尊重解析 TTL，合并并发查询，拒绝私网、环回和不相关 DNS 回答。
- 专用环回 CONNECT 隧道只允许连接该供应商主机和端口，不解密 TLS。
- 原始域名、SNI、证书验证、系统 CA、SSE 和取消信号仍由 Chromium 处理。
- 解析失败发生在模型请求发送前，不自动重放 POST，不修改全局 DNS/hosts。

已运行的旧版不会热替换网络实现。新包可准备为下次启动版本，不强退
ASS 或客户端，不更改其他供应商、账号或当前任务。
