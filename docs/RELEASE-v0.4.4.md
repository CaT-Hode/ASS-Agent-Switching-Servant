# v0.4.4

修复 Codex 图片生成工具被 ASS 路由返回本地 404 的问题。

- 原生图片工具沿模型供应商的接入地址发送 `POST /v1/images/generations` 和 `/v1/images/edits`。此前 ASS 只接收 Responses，图片请求尚未到达官方服务就被拒绝。
- 新增这两个精确入口，转发到 ChatGPT 官方 Codex 图片服务，保留当前 OAuth、账户、原生身份及图片回合标识。适用于普通 ASS 接入和提示词预测兼容接入。
- 图片模型不参与第三方对话模型路由。无账号模式、模型 API 专用凭据、缺失或过期的本机接入凭据不能调用官方图片服务；本机网关凭据需先换取官方 OAuth。
- 保留 JSON、压缩请求解码后的原始字节、multipart 边界和图片数据。大图片结果按流转发；官方错误状态、响应体和诊断头保留，日志不记录提示词或图片内容。

验证包括图片路由回归、官方转发及工作区 HTTPS 回归，以及当前安装的 Codex `0.163.0-alpha.10.2` 原生图片工具：隔离的 `openai` 和 `ASS` 对话分别通过实际路由完成生成、带参考图编辑和文件保存。使用虚拟 OAuth 与本地模拟上游，真实云端调用为 0；不代表用户账户额度或官方图片服务可用性已被验证。

本机安装采用 `--keep-running`，保留运行中的 ASS 和 Codex。新版本在下次正常启动 ASS 后生效。
