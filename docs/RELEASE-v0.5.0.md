# ASS v0.5.0

本版整合请求监控、模型协议选择、Claude Code 默认模型与 1M 上下文配置，以及客户端接入和界面改进。

## 模型与客户端

- Claude 接入页可分别设置 CLI 默认模型与 Auto Mode 审查模型，支持不同供应商；普通接入可启动默认模型终端，无账号启动后系统终端直接运行 `claude` 也生效。
- 上下文大于或等于 1,000,000 token 的模型，CLI 列表、默认模型、启动参数及审查模型自动添加 `[1m]`。路由匹配、上游请求、用量与监控归并使用原始模型名。
- 独立审查模型使用专用变量，并映射 Sonnet 别名兼容旧版 CLI；旧版的 `sonnet` 选择也使用审查模型。CLI 自行发起审查，不改变权限模式。配置区分草稿与已应用状态，撤回时恢复原字段。
- 各客户端接入页可逐模型选择自动或固定协议，补齐 Gemini 等模型在 Messages / Responses 间的选择与转换。
- 修复流未完成却被判成功、连接测试阻塞其他模型，以及模型检测耗时过长的问题；单模型测试共用 30 秒总时限，可独立取消。
- 改善 Codex 原生归档、旧对话预测绑定及图片请求路由的兼容性。

## 监控与界面

- 请求监控显示进行中与已完成请求，实时更新耗时、可见输出 TPS、缓存、供应商和协议，提供请求、模型和供应商视图。
- 主要 TPS 采用可见输出接收速率，估算显示 `≈`，无法形成接收区间时显示 `—`；详情保留推理用量与全程吞吐。
- 模型按最后一级名称归并，并移除 `[1m]` 标识。
- 主页面切换跟随左侧导航的上下位置；详情进入和返回使用左右过渡，同层切换淡入淡出。键盘操作与减少动态效果设置继续生效。
- 修正请求监控搜索框，README 重写为功能与操作说明。

## 使用与验证

更新后重新打开 ASS，修改接入设置后点击同步，再打开新终端或重新加载客户端。安装不会自动关闭正在运行的 ASS 或 Codex。

相关回归、原生 CLI 的独立审查路由、1M 临界值与后缀移除、打包界面均已验证。原生 CLI 检查使用隔离目录和本地模拟服务；不将其等同于供应商的长上下文能力实测。

Windows x64 提供一个完整安装 EXE，安装包校验值见本页发布附件信息。
