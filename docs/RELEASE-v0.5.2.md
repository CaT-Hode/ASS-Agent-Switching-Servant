# ASS 0.5.2

修复 Claude Code Auto Mode 的审查请求在 Messages 转 Responses 时被 `stop_sequences` 拒绝的问题。

- 已检测支持 Messages 的模型在 CC 中固定走原生 Messages，包括已有的跨协议覆盖设置；接入页显示实际使用的协议。暂时的检测超时、限流或服务错误不再把已确认的原生路由降级为转换路由。
- Responses 转换支持停止序列，处理跨数据块的匹配、过滤停止标记后的内容，返回正确的 `stop_reason` 与 `stop_sequence` 并取消上游读取。普通结束仍保留未匹配的文本。
- 停止序列不会将未完成的工具调用变为可执行调用。Auto Mode 的权限与审查流程保持启用。
- Codex、pi 的手动协议选择仍按各自设置执行，检测记录继续绑定对应的地址、凭据和网络配置。

沿用 0.5.1 的 WSL 自动同步与独立会话。保留运行进程的本地安装在下次正常启动 ASS 时启用新版。
