# ASS 0.5.3

新增可开关的桌面置顶请求悬浮窗。默认宽度 380px，无标题文字，模型名沿用末级归并规则。

- 每条请求单行显示模型、供应商、可见输出 TPS、缓存命中率及耗时，每秒更新十次。独立半透明圆角底层以颜色区分等待、输出、完成和失败。
- 完成后原位保留至少 15 秒，不重新排序；新请求可复用已完成行，过期的完成行合并清理，减少高度反复变化。
- 底部固定 2×12 无字热力格，每格对应今天一小时；悬停显示时间、输入、输出和总 Token。复用本地用量统计，补入最新统计之后的路由记录。
- 真实桌面 DXGI/WGC 采样与 GPU 折射；依据原始桌面亮度切换浅灰青蓝、深色灰紫配色。前景与材质分层，拖动位置和折射帧成对更新。
- 请求监控页与托盘均可开关，右键可调整宽度、圆角、行数；支持记忆位置、Esc 关闭和锁屏后重建图形资源。

开发构建原生部分需要 MSVC C++20、Windows SDK 与 CMake，`npm run build:native` 会下载官方 Node/Electron 开发头文件和导入库。打包自动构建原生模块，安装版无需开发工具。

本地安装保留正在运行的 ASS 与客户端，新版本在下次正常启动时生效。
