# ASS 0.5.4

请求悬浮窗保留清晰的桌面背景和边缘折射，移除整块背景的九点模糊。磨砂只留在热力格、请求行底层与提示框中，深浅配色继续以 240 毫秒渐变。

- 今日 24 小时热力格改为先从上到下，再从左到右：第一列 0、1 点，第二列 2、3 点，直到最后一列 22、23 点。悬停提示仍对应原来的小时。
- 移除右上角关闭按钮，保留右键菜单及 Esc。请求底层与热力格使用统一的内缩圆角，首行和热力格外沿按 16px 内距对齐。
- 请求明细在内存和磁盘中均仅保留最近 200 条，超出按 FIFO 删除；启动时合并旧轮转日志并裁剪。累计用量缓存和原始会话不参与删除，热力格继续使用完整的累计用量。
- 原生更新轮询由 16 毫秒缩短为 10 毫秒，驱动渲染队列限制为 1 帧。桌面帧采用零等待获取，亮度探针在 GPU 完成后非阻塞读回，不再为探针停住渲染线程；配色亮度检测仍约每 200 毫秒一次。
- 原生诊断增加渲染开始到 DXGI 提交呈现的耗时，供隔离对照验证；该值不代表显示器上的实际输入延迟。

本地安装保留正在运行的 ASS 与客户端，新版本在下次正常启动时生效。

验证：45 项相关回归及原生 GPU 合成纹理检查通过。隔离桌面各采样 100 帧，渲染到提交呈现的 P50/P95/最大值从 24.6/40.4/52.9ms 降至 16.2/26.8/32.3ms；这些数据包含软件调度，不是显示器输入延迟或刷新率。
