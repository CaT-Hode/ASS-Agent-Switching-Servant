# ASS 0.5.5

请求悬浮窗新增左入右出的条目过渡与窗口尺寸弹簧。数值更新沿用同一个条目节点，退出动画期间保留旧节点，完成后收回空间；完成条目仍原位保留至少 15 秒。减少动态效果时关闭位移与弹性。

- 窗口伸缩使用预分配的原生纹理容量，不重建捕获会话、D3D 设备或交换链。尺寸目标变化从当前尺寸和速度接续。
- 拖动位置直接采用鼠标坐标，移除横向速度驱动的形变回弹。采样原点、前景位置和可见尺寸随同一份提交帧更新。
- GPU 的 Draw、Copy、Present 保持同队列顺序，呈现不再等待下一次 CPU 完成查询；亮度读回仍等待 GPU 完成后非阻塞读取。
- 请求框与热力格改为真正作用于桌面采样纹理的局部 5×5 加权高斯磨砂，按屏幕物理分辨率渲染；区域外保持清晰。
- 折射边缘由 14px 增至 22px，默认圆角由 24px 增至 36px。旧默认圆角仅在升级时调整一次，后续自定义选择可保存。
- 供应商列由 50px 增至 64px，字号由 9.5px 增至 10.5px，模型名保留省略和完整悬停信息。

隔离桌面各采样 100 帧，渲染到提交呈现的 P50/P95/最大值从 16.1/26.1/31.3ms 降至 0.55/0.96/15.3ms；GPU 中位耗时约 1.15ms。该软件计时不包含显示器最终显示时间。

本地安装保留运行中的客户端，新版在下次正常启动 ASS 时生效；200 条 FIFO 明细规则与独立累计用量保留。
