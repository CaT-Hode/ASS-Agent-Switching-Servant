# 液态玻璃请求悬浮窗

在 **设置 → 请求悬浮窗** 开启桌面面板。悬浮窗始终置顶，可拖到屏幕任意一侧，松手后记住位置。按 `Esc` 或右键选择「关闭悬浮窗」即可收起。

## 定制外观

| 设置 | 调整范围 | 默认值 |
| --- | --- | --- |
| 窗口宽度 | 268–588 DIP | 288 DIP |
| 窗口圆角 | 8–48 DIP | 48 DIP |
| 最多请求行数 | 1–8 行 | 5 行 |

圆角越大，内容区从四边向内收得越多，为角落保留空间。

## 调整液态玻璃

在「液态玻璃」分组中调整边缘和背景折射。较宽的折射边缘会把效果延伸到更靠近窗体中心的位置。提高背景扭曲幅度会放大背景细节在边缘处的偏移。

| 设置 | 调整范围 | 默认值 |
| --- | --- | --- |
| 折射边缘宽度 | 6–64 DIP | 18 DIP |
| 背景扭曲幅度 | 0–100% | 40% |

外观与液态玻璃滑条均支持拖动、键盘和数值输入。拖动过程中，设置页实时预览效果，松手后应用到桌面悬浮窗。「恢复默认外观」会同时恢复窗口尺寸、行数和液态玻璃参数。

## 显示内容

- **请求行**。悬浮窗显示 ASS 路由请求与 Antigravity 原生观测。模型与状态始终显示，供应商、可见输出 TPS、缓存命中率和请求耗时可分别隐藏。开启「客户端（Harness）」可显示已识别的发起客户端，与显示处理方的「供应商」列各自独立。悬停请求行可看完整字段。已完成的请求最多停留约 15 秒，位置可由新请求复用。
- **今日 Token 汇总**。展示本地时间当天的总量、输入和输出，可独立开启。
- **今日 Token 热力图**。两行十二列对应 24 小时，按每列自上而下、再从左向右排列。悬停或聚焦格子查看该小时用量。
- **订阅额度条**。先为「额度条 1」选择窗口，需要两条时再设置「额度条 2」。可选项来自已查询到的 Codex、Claude Code 和 Antigravity 订阅百分比窗口。两条按选择顺序显示在热力图下方，关闭热力图后仍可显示。若列表为空，可先在路由总览的「账户与额度」查询订阅。

首次使用时悬浮窗关闭。开启后默认显示供应商、可见输出 TPS、缓存命中率、请求耗时和热力图。「客户端（Harness）」、今日 Token 汇总和额度条由用户选用。

拖动预览表头的竖线可调整相邻两列的宽度。也可以聚焦竖线后按左右方向键微调。拖动时实时预览，松手后保存并应用到桌面悬浮窗。隐藏的列会记住其宽度，点「重置列宽」可恢复默认布局。

## 怎么读数字

- **可见输出 TPS**按文本和工具参数的接收区间计算。短于一秒的已结束样本以 `*` 标记。没有独立输出计时的请求显示 `—`，或在具备全程吞吐时用 `~` 标记。
- **今日 Token**基于本地用量记录，并用最近扫描后观察到的请求补齐增量。只有日粒度的记录计入今日汇总。关闭热力图和汇总后，悬浮窗会暂停触发自己的本地用量扫描。
- **订阅额度**使用账户额度快照，英文窗口名称和剩余比例以等宽字体叠在半透明磨砂胶囊上，例如 `Codex · Weekly` 或 `Gemini · 5 Hours`。条体透出局部磨砂过的背景，并保留渐变和粒子动效。Codex 当前快照暂缺时，同一账号此前识别的窗口仍可选择。确认为零时显示 `0%`。额度来源不可用，或快照已经跨过重置时间时显示 `—`。

## 预览与桌面材质

设置页使用示例请求和热力图，预览所选列和窗口几何。额度条跟随所选订阅窗口，悬浮窗前景与材质配色跟随 ASS 主题。深浅主题共用同一张背景。[README 横幅](../README.md) 沿用预览背景，开启客户端列，使用八个受支持客户端和示例供应商展示请求行。

桌面悬浮窗使用 Windows 原生桌面采样与 GPU 折射，配色可随背景明暗变化。玻璃主体保持清晰折射，请求行和额度条背板各自使用局部磨砂。在支持的环境下，采样可由桌面帧事件唤醒，尺寸变化时使用同一帧内的采样位置、窗口边界与材质遮罩。活动请求按事件及时刷新，空闲时降低更新频率。
