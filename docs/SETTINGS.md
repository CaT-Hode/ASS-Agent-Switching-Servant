# ASS 设置

| 分类 | 可调内容 | 原入口 |
| --- | --- | --- |
| 常规 | 主题与开机启动 | 侧栏底部、关于 ASS |
| 请求悬浮窗 | 总开关、实时布局预览、最多请求行数、宽度、圆角、四个统计列、今日 Token 热力图和汇总 | 请求监控、托盘、悬浮窗右键菜单 |
| 客户端 | 默认工作目录、程序入口识别与覆盖、凭据检测目录、Kimi 配置版本、WSL 自动同步及发行版 | 客户端页的设置折叠区、识别按钮和工作目录行 |
| 用量与数据 | 应用内低额度提醒、供应商配置导入导出、打开数据目录 | 路由总览、供应商与模型、连接诊断 |
| 版本与更新 | 手动和自动检查、预览版本、下载、版本说明及原品牌互动 | 关于 ASS |

账号登录、模型接入、预览与同步、请求筛选、单账户额度关注、会话和项目操作继续在各自页面完成。已有接入异常时，确认框内仍可就地识别客户端。每个供应商是否同步到 WSL 仍随该供应商的模型配置管理。

悬浮窗里的模型和请求状态始终显示。关掉可选统计列会把位置让给模型名，悬停仍可查看完整字段。今日 Token 汇总包含总量、输入和输出，独立于热力图。两项都关闭时暂停悬浮窗触发的用量扫描。

宽度可按 1 DIP 调整至 268–588 DIP，圆角为 8–48 DIP，显示上限为 1–8 行。可拖动滑条、使用键盘或输入精确值。预览随拖动变化，松手后保存到悬浮窗。外观恢复只重置尺寸和行数。主题沿用日月开关。ASS 设置开关使用胶囊镜片，按住时镜片变宽、透出轨道与底图，拖动后松手提交一次。支持 Space 和 Enter。

## 后续可调项

1. **悬浮窗显示预设**。用 ASS 现有字段增加「专注」与「诊断」两种可选组合。专注保留模型、状态与耗时，诊断增加供应商、TPS 和缓存。用户仍可按项调整悬浮窗偏好。
2. **请求明细列选择**。在「用量与数据」提供 ASS 请求表的默认列选项。客户端、状态和时间默认显示，上游请求 ID 等排障字段可选。
3. **数据留存**。先展示 ASS 请求明细的保留范围、归档条数和占用，再评估保留期限及清理入口。
