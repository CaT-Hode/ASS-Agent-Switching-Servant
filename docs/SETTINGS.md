# ASS 设置

| 分类 | 管理内容 |
| --- | --- |
| 常规 | 浅色、深色、跟随系统，开机启动 |
| 请求悬浮窗 | 开关、实时预览、宽度、圆角、请求行数、液态玻璃折射、请求统计列、今日 Token 热力图与汇总、订阅额度条 |
| 客户端 | 默认工作目录、程序入口、凭据检测目录、Kimi 配置版本、WSL 同步与发行版 |
| 用量与数据 | 低额度提醒、供应商配置导入导出、打开 ASS 数据目录 |
| 版本与更新 | 手动与自动检查、包含预览版本、下载安装包、版本说明 |

## 常规

日月控件提供浅色、跟随系统和深色三种主题。开启「开机启动」后，登录 Windows 时 ASS 会在后台启动。

## 请求悬浮窗

「外观」控制尺寸与请求行数，「液态玻璃」控制折射边缘宽度和背景扭曲幅度。可拖动滑条或输入精确数值。拖动时右侧即时预览，松手后将设置应用到桌面悬浮窗。「恢复默认外观」同时恢复尺寸、行数和液态玻璃参数。

「显示内容」可按需选择请求列、热力图和今日汇总。「客户端（Harness）」默认关闭，开启后显示已识别的发起客户端。「供应商」列可独立控制。「订阅额度条」可选取最多两条独立的订阅额度窗口。[悬浮窗设置与数据说明](REQUEST-WIDGET.md)

## 客户端

「默认工作目录」用于从 ASS 启动客户端。未指定自定义目录时，使用 ASS 独立工作目录。

在「安装位置与同步」选取客户端，可自动识别程序入口，也可指定安装目录或启动文件。「凭据检测位置」列出 ASS 查找客户端账户的位置，支持指定其他目录或恢复默认。Kimi Code 可在新版与旧版配置之间选择。

Codex、Claude Code 和 pi 可以在此检测 WSL、选择目标发行版、启停自动同步或执行「立即同步」。每个供应商是否同步到 WSL，可在 **客户端与账户 → 供应商接入** 单独设置。

## 用量与数据

- **应用内低额度提醒**。选择剩余百分比阈值，或者关闭提醒。额度卡使用最近 15 分钟内仍在有效周期的成功查询。
- **供应商配置**。在本机导入和导出 ASS 供应商及模型。导出默认移除 API 密钥和额外请求头，导入后需要重新填写。选择包含密钥后，对应字段会明文写入导出文件。OAuth 登录令牌不在导出范围内。
- **ASS 数据目录**。查看并打开当前数据目录。Windows 下的默认位置为 `%APPDATA%\AI Switch Servant`。

账户登录、额度刷新、关注窗口和用量筛选仍在相应页面进行。模型接入、预览及同步由 **客户端与账户** 管理。

## 版本与更新

可手动检查更新，或开启自动检查。需要测试版时启用「包含预览版本」。找到可用版本后，页面提供发布说明与安装包入口。更新前应结束正在使用 ASS 转发的客户端请求，并从托盘退出 ASS。
