# 主题圆形揭幕

参考 [VitePress 官方主题切换示例](https://vitepress.dev/guide/extending-default-theme#on-appearance-toggle) 和 [Chrome 同文档 View Transitions 文档](https://developer.chrome.com/docs/web-platform/view-transitions/same-document)，使用浏览器保存的整窗旧 / 新视图，不复制另一套 React 页面。

- 新主题在 `::view-transition-new(root)` 中由 `circle(0px)` 扩张到覆盖最远角的半径，两种方向都让圆内显示新主题；旧主题在圆外保留。无默认交叉淡化、模糊或额外彩色描边。
- 圆心采用指针点击坐标；键盘、拖拽释放及自动模式采用主题按钮中心。支持任意位置的触发按钮，不写死左下角坐标。
- 时长 620ms，曲线 `cubic-bezier(.22,.8,.26,1)`；原有日 / 月 / 自动胶囊的弹簧拖拽保持独立。
- 相同实际深浅色不重复揭幕；系统减少动态效果、隐藏窗口或不支持 API 时直接切换。自动模式保存 `system`，由实际系统变化触发揭幕。
- 快速连续操作取消在途快照并直接采用最后选择，不排队、不锁按钮。取消后的旧回调不允许覆盖新选择；窗口改变大小或隐藏时清理过渡。
- Chromium 快照可能把点击重定向到根节点；仅在过渡期间，把命中主题按钮或窗口按钮范围的输入交还原控件，保留真实点击坐标和拖拽指针。不会拦截其他内容，也不创建第二套可操作 UI。
- Windows 的原生 caption overlay 不属于浏览器快照，因此改为页面内同位置的最小化 / 最大化 / 还原 / 关闭按钮。它们和页面一起受圆形蒙版控制。按钮只通过固定白名单 IPC 操作 ASS 自己的窗口，关闭仍使用既有的隐藏到托盘逻辑；不停止路由或原生 harness。
- 弹窗遮罩从顶栏下方开始。原生 modal 将顶栏标记为不可交互时，仅向固定窗口按钮交还命中范围内的点击；不会穿透弹窗去切换主题或触发后台页面，也不会因窗口操作顺带关闭弹窗。

窗口按钮为页面内绘制，未实现 Windows 11 原生最大化按钮悬停时的贴靠布局菜单；不将基本最大化 / 还原验证视为此菜单的验证。

新增的是自动遵循系统 `prefers-reduced-motion` 的兼容处理，不增加“减少动态效果”设置项。
