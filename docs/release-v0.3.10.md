- 圆形主题切换放缓至 960ms，使用 `cubic-bezier(.4,0,.6,1)`。前段推进更慢，中段峰值降低，后半程持续减速，起点 / 终点速度均为零。清晰圆形边缘、真实点击圆心与窗口按钮换色保持不变。
- 主题胶囊仍使用原有可打断弹簧：拖拽跟手、释放速度衔接、太阳 / 月亮 / 自动黄昏场景不变。
- 遮罩终点不再贴着最远角：额外增加 32–96px 的有界渲染余量，末尾重复完整覆盖帧，再解除快照，防止边缘突然消失、角落靠最后一帧补齐。
- 新增项目内 `skills/ass-theme-design`，总结整体深浅配色、双色 / 可选三档主题按钮、圆形揭幕与桌面窗口兼容，提供独立参考代码；可安装到个人 skills 目录。

实现与测试不调用云模型，不改变账户、配置或原生 harness。安装时保留旧版及开机启动设置，不强制关闭运行中的 ASS。
