# ASS v0.3.11

- 鼠标、键盘、拖拽释放与自动切换统一从实际触发按钮中心扩张，按钮搬动后圆心随之更新，不使用固定左下角或按钮内任意点击点。
- 可见扩张保持 960ms 总时长下的初慢 / 中快 / 末慢节奏。先完整覆盖四角，再扩到最远角距离的 1.6 倍加 48px，最后保持完整帧；大幅屏外扩张不加速可见末段。
- 修复已复现的提前取消路径：新色已提交后的同色系统 / 模式回声不再跳过正在进行的揭幕。尚未提交时的新选择仍覆盖旧请求。
- 重复 resize 与 2px 内的舍入变化不再取消动画；真正改变窗口大小、隐藏及失败仍按对应路径安全清理。
- 项目与个人目录内的 `ass-theme-design` 同步更新设计规则与参考代码。账户、会话、其他图标动画和配色不变。

本轮相关回归 28 项通过，前端构建与两份 skill 校验通过。隔离 Electron 实测覆盖双向切换、按钮移至右上角、长页面滚动、同色回声、重复 resize、键盘、快速反向与窗口控件；实际圆形半径呈慢—快—慢变化，四角在收尾前已完整覆盖。未强制关闭任何本机客户端，也未改动账户或会话数据。
