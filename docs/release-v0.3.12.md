# ASS v0.3.12

- 圆形切换的快照根层、根分组和图像显式铺满窗口，避免依赖快照默认尺寸与位移。
- 圆心取实际主题按钮中心，再转换为窗口百分比坐标；左下角按钮与临时搬动的按钮使用相同定位规则，不添加固定补偿偏移。
- 保留 960ms 初慢、中快、末慢曲线、四角覆盖与屏外收尾，以及同色同步保护。
- 项目与个人主题 skill 的参考代码和定位验证方法同步更新。账户、路由配置及会话数据不变。

本轮 28 项相关回归、构建与两份 skill 校验通过。隔离 Electron 中，8 组原生截图像素检测的圆心与按钮中心误差均小于 1 CSS 像素（最大约 0.063），覆盖长页面、滚动、80% / 125% 页面缩放、键盘、双向切换和按钮临时移位。真实用户截图中偏移的原始触发条件尚未在隔离环境复现，验证结果不等同于已经在用户运行中的旧版应用核验。
