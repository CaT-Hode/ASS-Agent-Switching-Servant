# ASS v0.3.13

- 保留 v0.3.12 的窗口快照约束与实际按钮圆心定位。
- 最终半径统一为 `hypot(windowWidth, windowHeight) * 1.6 + 48px`，不再取“圆心到最远角”的 1.6 倍。即便按钮在窗口中央，最终半径也严格大于窗口完整对角线。
- 可见阶段的半径、960ms 时长和慢—快—慢曲线不变；新增半径只在四角覆盖后用于屏外扩张，不加速可见末段。
- 项目与个人主题 skill 同步更新。账户、配置和会话数据不变。

验证：29 项相关回归通过；最终半径断言覆盖中心、边缘及最高 7680×4320 窗口。隔离 Electron 的实际动画在 1440×960 窗口测得最终半径约 2817.06px，大于约 1730.66px 的完整对角线；8 组原生画面圆心比对和双向、键盘、滚动、自动档、弹窗窗口控件测试通过。原用户截图中偏移的触发条件尚未在隔离环境复现。
