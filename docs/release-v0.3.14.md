# ASS v0.3.14

- 主题揭幕采用 `cubic-bezier(.28,0,.45,1)` 非对称 S 曲线，总时长 1080ms：更早展开、峰值前移并受控、长尾连续减速，两端速度为零。
- 保持实际触发按钮圆心及整窗快照约束。在快照就绪时复核实际图像盒尺寸，半径按整窗与快照较大尺寸的完整对角线 `D` 计算。
- 主扩张半径为 `D + max(64, D * .04)`，最终半径为 `D * 2 + 96`：主阶段和最终阶段都超过窗口对角线，不只依赖最后的屏外帧。最后 5% 保留完整帧。
- 屏外扩张仍只发生在四角完整覆盖后，胶囊拖拽弹簧和配色不变。
- 项目与个人主题 skill 增加整条速度曲线的调节与验证原则；参考代码同步更新，不改账户、配置和会话数据。
- 将暂停、跳帧取样测试与连续播放演示明确分开。采样脚本的 `pause/currentTime/finish` 会人为制造画面跳变，不作为正常播放证据。
- 独立 Electron 连续演示完成四次深浅切换，没有操纵播放进度；1440×960 窗口对角线约 1731px，最终半径约 3557px，结束前保留 5～6 帧完整覆盖，未出现页面错误。
