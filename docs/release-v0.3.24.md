# ASS v0.3.24

- 所有注入模型的默认最大输出改为 128K（131,072 token），不改变模型总上下文长度；上下文较小的模型按其窗口限制输出。
- 模型详情页可单独调整输出上限，显式设置的较小请求预算仍保留。
- 启动时一次性迁移旧配置中未设置或沿用 16K 的默认值，包括供应商配置、Codex / Claude 已应用路由、OpenCode / pi / DSH / Kimi / ZCode 的受管字段；其他数值保留。
- 已有客户端文件存在外部修改或未完成的事务时，迁移会保留现场并显示待同步状态。迁移不关闭或重启客户端，不修改原生账户、密钥或项目会话。
- 新版中再次手动设置 16K 会持久保留，不会在后续重启时再次迁移。
