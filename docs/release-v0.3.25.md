# ASS v0.3.25

- 已接入客户端的同步按钮立即打开确认弹窗，不再预先刷新账户、额度或模型目录；本机接入预览在弹窗内完成，等待期间可取消。
- 检测到 Codex OAuth 登录时，默认模型选择器包含官方 GPT；无账号模式仍只允许注入模型。
- 关闭 Codex 接入时，先将 ASS 会话的供应商绑定恢复为官方供应商，并为第三方模型设置官方续聊选择；消息、工具结果、标题、归档和置顶状态保留。
- 历史记录含第三方思考块时，追加原生兼容的续聊上下文，排除官方接口不接受的思考状态；原始思考和消息仍保留在日志中。旧版压缩 / 回退格式无法确认时保留现场，不猜测或重新引入已移除内容。
- 会话恢复需先关闭 Codex，或在关闭接入弹窗选择强制关闭 / 重启。客户端正在运行、会话被外部修改或事务未完成时，不删除仍被对话引用的接入定义。
- 已关闭接入但残留 ASS 会话绑定时，客户端页提供“恢复官方续聊”，通过同一确认流程处理。
- CC 返回官方配置时清理失效的网关模型选择及缓存；独立配置的第三方网关和原有对话记录保留。已运行窗口需重开才能加载官方配置。
- 包含 v0.3.24 的统一 128K 默认最大输出及旧默认值迁移。
