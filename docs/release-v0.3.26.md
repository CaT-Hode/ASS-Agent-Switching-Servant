# v0.3.26

修复 Codex 桌面版在 ChatGPT 订阅额度耗尽后，一并禁止第三方模型发送新消息的问题。

- 常规模型注入使用 Codex 原生 custom-provider API 认证及 ASS 本机凭据。桌面端不再把整个输入框绑定到 ChatGPT 账户的额度判断。
- 官方 OAuth 原文件保留。普通接入仍可选择官方模型；ASS 仅在收到官方模型请求时读取当前官方登录。过期令牌交由原生 Codex app-server 刷新，不自行实现 refresh grant。
- 官方额度限制如实返回，第三方请求不读取官方授权，也不依赖官方额度。无账号启动仍只展示和允许注入模型。
- 已接入用户需重新同步 Codex 接入，再完整退出并重新打开 Codex。安装 ASS 本身不会重启任何客户端；旧窗口已缓存的桌面状态不能仅靠改写路由即时刷新。
- 接入期间 Codex 桌面显示自定义 API 模式；订阅账户与额度仍在 ASS 客户端账户卡片中管理。依赖 Codex 桌面 ChatGPT 登录的云端功能需关闭接入后恢复。

原因核对基于本机 Codex 26.928.2636.0、后端 0.159.2 的安装包及隔离原生 app-server 实测。未修改 Codex 安装包、伪造额度响应或删除登录记录。
