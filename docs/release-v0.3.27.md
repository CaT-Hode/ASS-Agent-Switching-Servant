# v0.3.27

补齐 Codex 官方路由的 HTTP 透传，避免 ASS 丢失原生请求标识、用量信息和上游错误证据。

- 官方请求透传 User-Agent、语言、Codex 扩展头、会话标识和追踪信息；过滤连接专用头、Cookie、代理凭据及 ASS 本机控制头。解压和历史兼容处理后重建请求体的长度与编码信息。
- 官方响应保留状态码、request ID、限流、Retry-After、用量及网关标记。错误正文直接传回客户端，不再一律包装成 ASS 的通用 JSON 错误。错误中回显的已知凭据仍会脱敏。
- 官方 SSE 保留心跳、事件 ID、CRLF 和原生失败事件，不再重排流内容；继续检测任务结束及不完整响应。
- 请求日志增加关联 ID 和有限的上游诊断头，HTML 错误只记录分类及标题，不保存整页、请求正文、Cookie 或 OAuth。
- 第三方模型继续使用独立的供应商凭据，不透传官方 OAuth 或账户标识；保留现有历史兼容、请求取消与接入限制。

此更新补齐 HTTP 语义和诊断信息，不保证消除上游网关自身返回的 403；不更改 DNS、系统代理、CA 或官方账户，也不自动重启客户端。
