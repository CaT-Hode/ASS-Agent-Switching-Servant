# v0.3.29

修复 v0.3.28 开启 Codex 接入后账户读取失败、界面要求重新登录的问题。

- 新接入不再改写 `chatgpt_base_url`。官方账户、workspace、插件和远程控制继续使用原有后端，模型调用仍通过 ASS 的 `/clients/ASS/v1` 路由。
- v0.3.28 的旧接入会显示待同步；重新同步或“一键修复”均可恢复原账户地址。修复只使用已应用的模型配置，账户文件不变。
- 恢复账户地址与更新接入记录使用同一事务，失败时完整回滚；之后关闭接入仍能恢复原配置。
- 保留模型请求的 HTTP/SSE 透传、上游诊断和凭据隔离。
- 原生账户检查使用产品实际生成的完整注入配置，校验账户与 workspace 路由，而非仅检查缩减版供应商配置。

此版本修复本地 HTTP 地址触发的 workspace HTTPS 校验回归；不更改官方 workspace 策略，也不保证消除官方出口或网关自身返回的 403。
