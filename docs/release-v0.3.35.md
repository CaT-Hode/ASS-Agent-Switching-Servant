# v0.3.35

修复实际深浅配色变化时，左下角主题胶囊的滑块出现停顿 / 跳变。

- 根因：全屏 View Transition 的旧 root 截图包含静止的旧按钮；底层滑块虽由弹簧连续移动，却要等圆形新主题覆盖后才能显现，造成绘制位置与实际位置不同步。
- 主题胶囊在圆形过渡期间使用独立的命名过渡层，只显示实时的新视图；取消该层默认交叉淡化与几何动画，保留原本的滑块弹簧、拖拽和场景动效。
- 页面仍使用原有圆心、完整半径与 2000ms 非线性曲线，没有缩短或取消圆形过渡。
- 弹窗遮挡主题按钮时不提升按钮层，避免穿透弹窗。
- 项目内可复用主题模板同步 CSS 修复；没有修改本机全局 skill。

遵循用户要求，不关闭或替换当前运行的 ASS / Codex，新包单独准备。
