# v0.3.36

包含 v0.3.35 的主题滑动跳变修复，并增强“自动”落日档的胶囊内部动效。

- 小日轮在固定地平线后缓慢沉降 / 升起，周期 6.8 秒；光晕和暖色内光同周期呼吸。
- 三层地平线反光错相伸缩、上下轻移并呼吸，周期 3.8 秒。
- 动画仅作用于图标内部与装饰层，不改变滑块位置，不与拖拽弹簧争用 transform。
- 拖拽、滑动和隐藏时暂停，恢复时保留相位；太阳 / 月亮档不会残留落日位移，系统减少动态效果时关闭装饰动画。
- 项目内可复用主题模板同步，未修改全局 skill。

当前运行的 ASS / Codex 保持不动，新包不自动替换。

## 验证

- 31 项主题相关测试通过，包括自然播放中的原生像素采样、双向配色切换、拖拽反向、自动模式、弹窗遮挡和减少动态效果。
- 新增落日测试验证日轮、内光和反光线确实变化，滑块本身不漂移；拖拽暂停后动画保留相位。

- 最终包 147 个运行时文件一致；独立空账户的打包版启动检查通过，页面错误为 0。
- 当前 current 仍是 v0.3.32，运行中的 ASS / Codex 未关闭或替换。没有修改账号、OAuth 或路由配置。
