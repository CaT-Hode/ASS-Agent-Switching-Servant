# v0.3.39

- 去除深浅切换胶囊外沿的装饰描边和内阴影，保留原几何与键盘焦点提示。
- 日落档的太阳光线在固定遮罩后以 8.8s 周期独立旋转；日轮、地平线和滑块不随光线旋转。
- 加强滑块下方三层错相波纹，扩大扩散范围和峰值可见度；海浪细线更清晰、水平起伏更明显。
- 旋转和波纹在拖拽、滑动及隐藏时暂停，减少动态效果时停用。不改变整窗圆形切换或账户、路由配置。
- 根据最终实现同步项目和本机的 best-light-dark-switching 资源与说明。

支持 `node scripts/local-release.cjs install --keep-running --json`：将开始菜单与 ASS 注册入口固定到新版，保留当前进程及其 `release/current` 目录，不热替换其资源，不清理旧包；下次正常启动使用新版。普通安装模式的进程保护仍保留。已有开机启动入口仅更新路径，不启用关闭中的开机启动。
