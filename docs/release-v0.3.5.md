# ASS v0.3.5

- Codex 模型切换：修复从 DeepSeek 等第三方 Responses 模型切回官方 GPT 时，历史 `reasoning.content` 非空导致的 `Invalid 'input[…].content': array too long`。仅过滤发送给官方 Codex 后端的请求副本中不兼容的整条思考项，不将供应商的加密状态单独留下；原始历史、正常问答、工具调用与结果、图片及有效的官方思考状态不改动。第三方原生 Responses 路由保留自身思考项，官方 `/compact` 使用同一规则。
- Codex 归档删除：Windows 上 Codex 0.162+ 运行时也可删除闲置的原生归档会话，使用原生协调锁与会话锁确认没有写入者。被占用、非归档或存在分支历史引用时拒绝删除，不结束 Codex 进程。
- 删除确认：对话与项目记录删除仅做一次二级确认，不再保存新的正文恢复备份；已有旧备份仍可恢复。项目目录、代码文件和凭据不删除。
- 删除中断：保留不含正文的最小删除事务记录，重新启动后继续识别部分完成的操作，避免已删除会话重新出现。

## 验证范围

本机全量测试 **831/831 通过**，包含 9 项历史过滤回归、本地 HTTP/SSE 模拟上游、原生归档锁及删除持久化测试。使用实际报错会话的日志在内存中离线重放，15 个历史项仅移除 1 个不兼容思考项，原始文件字节未变，未发送远端推理请求。

生产包的 **134 个运行文件**与源码及构建产物一致，不含测试、QA 入口或用户数据。本机 `release/current`、开始菜单入口及应用图标注册已更新到 0.3.5；未自动启动 ASS 或关闭 Codex。未执行 Windows 安装 EXE 的安装/卸载流程，不修改用户原始会话、OAuth 或模型接入配置。
