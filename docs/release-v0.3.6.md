# ASS v0.3.6

修复 v0.3.5 项目会话同步 QA 确认的四项问题。

- OpenCode 1/2 默认恢复显式采用当前配置的供应商和模型，投影元数据同步携带目标模型。不再写死 `openai/gpt-5`；模型无法确认时提示先配置，不静默使用历史模型。
- Claude Code 保留同一回复中不同 `apiBlockIndex` 的文本块，只替换同一块的快照；不同轮次复用上游消息 ID 不覆盖此前回复。
- pi 按最新 compaction 的有效保留范围同步，摘要在前，不把压缩前旧内容带回目标。
- pi 应用活动上下文中的 `context_edit` 删除、替换及覆盖顺序，不改变原消息角色。
- 升级后重新解析旧缓存；已同步上下文被修正时停用旧投影，防止回流，旧共享内容可只读查看，不用于续聊。原始客户端日志不改写。
- 共享预览增加可展开的同步范围和来源提示：系统提示、工具许可、插件、凭据及附件正文不迁移。仅传递存在标记，不把历史提示提升为目标系统指令。
