# ASS v0.3.7

包含此前 v0.3.6 的会话同步、模型统计和 Claude Gateway 修复，以及本轮路由总览和浅色模式调整。

- “账户与额度”优先展示已返回的额度窗口、余额及订阅档位。没有这些信息的 Key 收入默认折叠的“其他账户”，零余额和已用尽的额度仍正常显示。
- 同一 API 绑定多个客户端时只显示一个账户，优先采用有实际额度信息的绑定；刷新失败不丢弃已缓存的有效数据。
- 浅色模式应用内 logo 使用黑色花瓣，橙色中心及权威矢量轮廓保持不变；顶栏和关于页统一。Windows 图标资源不随应用主题改写。
- 浅色模式的活跃热力格、图例、Token 图表和模型用量条使用天蓝色深浅梯度；周额度条使用天蓝色，5h / 周 / 月保持各自的颜色。深色模式保留原有紫色统计。
- 对话管理客户端选中项采用对比更强的中性灰底色及深色文字，不引入公共界面的蓝调。

## 验证范围

本轮使用隔离的 Electron / Playwright 实例、1440 × 960 桌面窗口和模拟账户，验证浅色、深色及跟随系统主题、客户端选中交互、热力配色变量和额度条实际样式。没有修改真实账户、停止原生 harness 或发送真实云模型请求。

最终全量回归 866 / 866 通过，前端构建和独立桌面主题验证通过。深色额度条及动画继续与改色前的基线一致，仅允许显式的浅色调色覆盖。

Claude Desktop 2.9939.4.0 的 `supports1m` / `prefer1m` 仍受原生模型选择器实现限制；本版不宣称已消除额外 1M 条目，也不修改 Claude 安装文件。

本地更新使用独立版本目录和 `release/current` 入口，保留旧版本及用户数据，不自动启动 ASS。
