# ASS v0.3.9

- 增加整窗圆形主题揭幕。从实际点击点向外扩张，圆内显示新主题、圆外保持旧主题，边缘清晰，无模糊或默认交叉淡化。620ms 非线性曲线，半径自动覆盖最远角。
- 主题胶囊的点击位置、键盘中心、拖拽释放和自动模式使用同一入口，保留原有日 / 月 / 自动场景和弹簧反馈。相同实际深浅色不重复播放动画。
- 快速反向操作取最后选择，取消旧快照并清理 `fill:both` 动画；过渡期间的按钮输入转交真实控件，不等待旧动画结束。窗口尺寸变化、隐藏、减少动态效果及不支持 API 时安全降级。
- 右上角最小化 / 最大化 / 还原 / 关闭按钮与圆形蒙版一起换色，使用受限 IPC 仅操作 ASS 自身窗口。关闭仍隐藏到托盘，不停止路由或 harness。页面内绘制按钮未实现 Windows 11 原生悬停贴靠菜单。
- 包含 v0.3.8 的浅色热力图方向修正：浅色少、深色多；深色热力图、其他用量图表及额度条不受影响。

实现说明及官方参考见 [主题圆形揭幕](THEME-TRANSITION.md)。

## 验证边界

879 项全量回归与前端构建通过。使用隔离的 Electron / Playwright 测试实例、1440 × 960 桌面窗口验证双向圆形蒙版、动画中途及结束的右上角像素、连续点击、键盘、自动模式和减少动态效果；实际测试该实例在弹窗开启时的最大化 / 还原 / 最小化 / 关闭到托盘，控制台无页面错误。窗口操作不会顺带关闭弹窗，主题按钮不会接收弹窗背后的点击。

未使用真实账户或云模型，未关闭、配置或重启用户的 ASS / 原生 harness。本轮推送源码，不自动替换本机 v0.3.8，不发布远端安装包。
