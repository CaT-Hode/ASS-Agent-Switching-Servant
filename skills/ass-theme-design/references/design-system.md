# 配色与按钮设计

## 基调和层次

大面积使用中性灰，不给所有表面染绿，也不用黑白强反差描边。以下是 ASS 的起点，不要求其他项目像素级沿用。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 `surface` | `#f3f3f3` | `#1a1a1a` |
| 侧栏 `sidebar-surface` | `#ebebeb` | `#242424` |
| 主面板 `panel` | `#ffffff` | `#252525` |
| 抬升 / 悬停 `raised` | `#ededed` | `#303030` |
| 次级区域 `subtle` | `#efefef` | `#2c2c2c` |
| 选中 `selected` | `#e6e7e6` | `#363636` |
| 正文 `ink` | `#272928` | `#e4e8e5` |
| 次级文字 `muted` | `#69706b` | `#a3aaa5` |
| 辅助强调 `accent` | `#575b58` | `#b0b4b1` |
| 主操作 `primary` | `#5c605d` | `#6e726f` |
| 边界 `border` | `#18251d0b` | `#ffffff0a` |

绿色仅存在于文字 / 辅助强调的轻微色偏。卡片优先用底色、间距和少量阴影分区；边界低透明，悬停不突然变成亮绿框。可操作状态仍必须清楚，不能以“无感”为由消除焦点或选中状态。

主内容文字保持可读对比度，小字号通常至少 4.5:1。错误、警告、成功保留语义色，不为了统一灰调而隐藏状态。

用 `light-dark(light, dark)` 或现有主题变量实现，主题状态要驱动 `color-scheme`。自动模式需要独立的“所选模式”和“实际浅 / 深配色”。覆盖表单、滚动条、菜单、弹窗、提示、禁用与选中状态，避免深色页面中出现遗留白色表面。

## 数据色，不是全站强调色

- 用量 / Token 图表：浅色天蓝、深色紫色；同一 token 定义显式成对配色。
- 活跃热力图：浅色由浅到深表示少到多；深色紫色由暗到亮表示少到多。零值使用接近底色的灰，不当成第一档数据。
- 示例热力格 1–4：浅色 `#ade0f3 → #61b8df → #218dc0 → #155d85`；深色 `#49325f → #74509b → #9f76c7 → #c79aed`。
- 普通用量条可以使用天蓝 / 紫色的暗到亮渐变，不为热力图方向而反转全部图表。
- 多时间窗口用量条保留各自可辨认的语义：ASS 的短窗口蓝、周窗口浅色天蓝 / 深色紫、月窗口青绿。不要把所有窗口强行改成同色。
- 用量条没有白色端点球；可使用非常低幅的星点与柔光，不沿用到侧栏、供应商 logo 或所有按钮。

logo 的单色轮廓随主题使用浅色黑、深色白；保留彩色中心 / 品牌本身的颜色和几何，不对任意第三方 logo 盲目 `invert()`。

## 主题胶囊

形态是横向长胶囊，接近其所在侧栏的有效宽度；不是一个孤立的窄开关。ASS 起点为高 40px、圆角约 22px、两侧内缩 3px、圆形滑块 32px。滑块行程根据实时宽度计算，不靠固定像素猜。

左为浅色太阳，右为深色月亮；若支持自动，黄昏位于中间。太阳 / 月亮同时影响场景背景、云层、星点和地平线，不只是替换一个图标。双色版本移除中间停靠点与相关场景；不要悄悄保留可进入却不可见的自动档。

| 模式 | 形态和场景 | 轻微静置动效 |
| --- | --- | --- |
| 浅色 | 正向太阳、淡暖色圆盘、柔白云层 | 光芒缓慢转动约 20s，云漂移 6–8.5s |
| 深色 | 稳定月体、星空、低亮月缘 | 月食遮影往返约 24s，星点错相呼吸约 3.2–5.4s |
| 自动（可选） | 黄昏 / 清晨暖色天空、半日轮和水平地平线 | 地平线轻呼吸约 3.2s，晨昏光约 7s |

三种场景可共用约 6s 的低透明多层波纹（峰值不超过约 .15），局限在胶囊内。月食移动遮影，不旋转整个月亮。非当前场景不运行；隐藏、拖拽、弹簧过渡时暂停，不在释放时重置到任意相位。

在按下时立即反馈，拖动时跟随真实指针。不要给整颗滑块和场景各自增加不同 CSS 延迟。样式由一个呈现进度驱动所有层，不靠独立循环切换状态。

图标不替代可访问名称：明确当前浅色 / 深色 / 自动，自动还可以给出当前实际主题。键盘至少支持左右、Home、End；保留焦点样式。尊重系统减少动态效果，不需要额外增加一个设置项。
