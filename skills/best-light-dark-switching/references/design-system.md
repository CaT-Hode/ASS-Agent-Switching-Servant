# 配色与场景

这是当前项目的主题实现摘要。复用时以目标产品的内容和用户要求为准；参数可调整，不要求照搬品牌、图表或布局。

## 配色取向

中性灰黑 / 柔白为大面积底色，低饱和灰绿只作细微辅助。靠表面明度、间距和少量阴影分区，避免亮描边或给整站染上强调色。

| token | 浅色 | 深色 |
| --- | --- | --- |
| surface | #f3f3f3 | #1a1a1a |
| sidebar-surface | #ebebeb | #242424 |
| panel | #ffffff | #252525 |
| raised | #ededed | #303030 |
| subtle | #efefef | #2c2c2c |
| selected | #e6e7e6 | #363636 |
| ink | #272928 | #e4e8e5 |
| muted | #69706b | #a3aaa5 |
| accent | #575b58 | #b0b4b1 |
| border | #18251d0b | #ffffff0a |

实现使用语义 token、`color-scheme` 和 `light-dark()`。同时检查菜单、表单、原生滚动条、弹窗和禁用状态，不只更换页面底色。

数据色与全站强调色分开。当前项目浅色用天蓝、深色用紫色；热力格分别由浅到深 / 由暗到亮表示少到多。额度条颜色不改变已用 / 剩余语义。迁移时保留目标产品既有数据含义，不把这套图表配色强加给所有产品。

## 胶囊与场景

参考胶囊高 40px，接近侧栏的有效宽度，圆形滑块 32px。外沿无装饰性亮边和内阴影，保留透明 1px 边框维持测量几何；仅键盘聚焦时显示焦点提示。行程实时测量，不写死宽度。左侧太阳、中间可选自动、右侧月亮；位置与图形共用呈现进度。

| 模式 | 实际场景 | 当前参考动效 |
| --- | --- | --- |
| 浅色 | 暖白太阳、柔白云层 | 光线独立旋转 42s，云漂移 6–8.5s |
| 深色 | 正向月体、低亮星空 | 月食遮影约 24s，星点错相呼吸 |
| 自动 | 落日 / 清晨、地平线、可选海面 | 半日轮后光线旋转 26.4s，日轮升沉与内光 6.8s，反光线 3.8s，海浪 5.2–8.4s |

### 当前海边落日

胶囊上部保留暖色天空，下部使用清晰的蓝色远近海面与细海平线，形成冷暖对比。浅色系统中海面由 `#85b4c9` 过渡到 `#386f9a`；深色系统中由 `#467a9f` 过渡到 `#204566`。金色倒影向近处展开，淡蓝波纹和倒影缓慢错相运动。

蓝色只属于控件内部的海景，不扩散到全站背景、按钮或描边。不要为遵守中性色基调，把海洋重新去色成灰绿。

海面由 `--theme-twilight` 控制显现，太阳 / 月亮两端归零。SVG 渐变使用实例唯一 ID；不新增位图或网络资源。场景只存在于控件内部，不改变全站配色。

日轮在固定的遮罩 / 地平线后升落；月亮移动月食遮影而非旋转整个月体。装饰动画只影响内部层，不占用滑块外层的 transform。拖拽、弹簧滑动和隐藏时暂停，恢复保留相位。减少动态效果时停用装饰。

太阳的旋转只落在光线组，不能旋转地平线或滑块。三层底纹以 4.8s 错相向外扩散，参考峰值透明度 .28、最大缩放 4.2；海面波纹水平移动约 ±14px，并通过较清晰的细线体现波动。增强存在感但不增加胶囊外沿的固定光圈。

## 迁移边界

- 保留目标项目已有品牌与业务内容；单色 logo 的主题处理需要实际检查，不对第三方图标一律反色。
- 不需要自动档时，同时移除中间停靠点、点击映射、键盘索引和落日场景，不能只隐藏图形。
- 当前参考仅针对横版桌面；其他布局由目标任务明确决定，不额外重排页面。
